ADMIN PANEL SETUP

1. GitHub में admin.html, admin.js और admin-style.css upload करें.
2. Supabase SQL Editor में admin-setup.sql का पूरा code Run करें.
3. admin-setup.sql के अंत में अपने Admin account को add करने वाली INSERT line में अपना login email डालें और Run करें.
4. Admin Panel खोलें:
   https://YOUR-GITHUB-USERNAME.github.io/My-Coaching-Site/admin.html

Admin Panel Features:
- सभी Coaching Owner की details
- Search
- Edit Coaching details
- Delete Coaching
- Total Coaching count
- Total Batch count
- Public Page Open
